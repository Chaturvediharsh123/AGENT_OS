Features

Everything you need to run agents as a team

Not another chat box. A command center for dispatching, observing and shipping multi-agent work.

Crew handoff orchestration

Agents run in sequence and each one builds on everything the crew produced before it. Research becomes analysis becomes a draft becomes a reviewed result — not four disconnected answers.

# POST /api/runs { "task": "Draft a launch brief", "routing": "Crew handoff", "agent_ids": [1,2,3,4] }

Local-first

Ollama by default. “Local only” routing refuses to send a byte to the cloud.

Live pipeline

Watch every step move from queued to running to done, with timing and errors inline.

Approval gates

MCP connectors get scoped permissions. Anything with side effects waits for you.

Workspace memory

Every mission is searchable. Hit Ctrl K and jump to any past answer.

Replay, compare, export

Re-run any mission in one click, view agent outputs side-by-side, and export the result as Markdown or a print-ready PDF.

Bring any model

Mix Ollama, OpenAI, Anthropic and Gemini agents in one crew. No Ollama? Flip on the labelled demo provider and present anyway.

How it works

reviewed result in three moves

1

Describe the outcome

2

Assemble your crew

Pick one agent or the whole team, then choose a strategy: parallel, crew handoff, or local only.

3

Watch, review, ship

Follow the live pipeline, open each step, compare outputs, then export or replay the mission.
